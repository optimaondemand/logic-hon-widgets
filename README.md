# Semantics and Logic Honors — Interactive Widgets

Self-contained HTML/CSS/JS widgets embedded via iframe into Canvas lesson pages for
Optima Academy Online's Semantics and Logic Honors (CPALMS 1004300) course.

Hosted via GitHub Pages from this repo's root. Each file is standalone — no build step,
no external dependencies.
